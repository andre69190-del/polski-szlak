# Muttersprachler-Aufnahmen

Hier liegen echte Aufnahmen (z. B. `waw/dzien-dobry.mp3`). Eingetragen werden sie in `src/data.json` unter `"audio"`:

    "audio": { "Dzień dobry": "audio/waw/dzien-dobry.mp3" }

Die App spielt dann beim Vorlesen die Aufnahme statt der Gerätestimme. Anleitung: `docs/AUDIO_AUFNAHMEN.md`.
